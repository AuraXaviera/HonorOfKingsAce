# Honor of Kings Ace — Golden Shards (Zenith Launcher)

Data terjemahan (Bahasa Indonesia / Global English) untuk **Zenith Launcher**. Launcher mengunduh `shards_manifest.json`, lalu zip shard yang sesuai, dan memverifikasi SHA-256 sebelum menyuntikkannya.

| Berkas | Isi |
|---|---|
| `online_shards/shards_manifest.json` | Manifest 2.0 (sumber utama; kompatibel mundur: bagian `packages` = format lama v1.8.2, `packagesV2` = paket resmi) |
| `shards/golden_shards_id_v2.zip`, `shards/golden_shards_en_v2.zip` | Paket QtsVFS 1 dan 4 hasil mesin resmi (mirror; berkas utama ada di Release) |
| `shards/golden_shards.zip`, `golden_shards_en.zip` | Format lama (launcher <= 1.8.2) |

Hash dan ukuran semua zip dihitung langsung dari berkas oleh skrip rilis; lihat `RELEASE_NOTES_v1.9.0.md`.

> Modifikasi data game pihak ketiga. Tidak ada jaminan bebas penalti akun; gunakan dengan risiko sendiri (disarankan akun cadangan).
